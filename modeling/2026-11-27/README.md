# November 27 GITT reproducibility package

These scripts correspond to the new Figure 6 and SI Figures S7–S12, Table S7–S11. The raw records and pulse-level data are stored privately, not in this public repository. Retrieve the private package `HEO_Figure6_SI_2026-11-27.zip` or original four xlsx workbooks through the PI-owned source location. The archive contains scripts, derived data CSVs, and vector and raster graphics. The public texts report aggregate numerical results in the integrated SI.

Required Python libraries: numpy, pandas, scipy, matplotlib. The source names expected by the parser are aliases HEO.xlsx, BM.xlsx, Mg.xlsx, BM_Mg.xlsx. The scripts generate data in a local data directory and figures in figures. See individual script docstrings and --help. To reproduce, stage source files locally under the four aliases; run recompute_pulse_metrics.py with --raw-dir and --out-dir data, followed by recheck_charge_model.py, supplementary_tables.py, make_figures.py, and waveform_supplement.py with --raw-dir. The comparison uses 1,020 completely rested pulses (282/327/190/221), 24 half-cycle totals, signed 3–3600 s recovery, and separate 3–3500 and 10–3500 s conditional comparisons. See the integrated SI for definition, denominators, and model limits. Figures and results are review assets, not independent validation or new measurements.
