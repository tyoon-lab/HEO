## Scientific identity

The t63-defined R1–R4 intervals localize modification-dependent signed nominal GITT charge changes during first lithiation: largest R2 gain for ball milling, largest R3 loss for Mg incorporation, differing movement of operational boundaries. Subsequent same-cell cycles show persistent opposing accessible charge effects, and milling changes delithiation charge–potential distribution and voltage-relaxation response. These are quantitative electrochemical observations; literature supplies candidate overlapping chemical processes, not independently isolated reaction fractions. Primary relaxation uses 3–3600 s and first crossing from 3 s. Conditional model tests use specified reference/endpoint inputs and do not identify a microscopic rate constant.
